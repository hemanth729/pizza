# Pizza Sales Power BI Dashboard

## Overview

This repository contains a Power BI dashboard analyzing pizza sales data. The dashboard provides insights into sales trends, customer preferences, and revenue generation.

## Dataset

The dataset used for this dashboard includes **48,620 records** of pizza sales with the following columns:

- `order_id`: Unique identifier for each order.
- `order_date`: Date when the order was placed.
- `order_time`: Time when the order was placed.
- `pizza_id`: Unique identifier for each pizza.
- `pizza_name`: Name of the pizza.
- `pizza_size`: Size of the pizza (Small, Medium, Large, etc.).
- `pizza_category`: Type of pizza (Classic, Supreme, Veggie, etc.).
- `pizza_ingredients`: List of ingredients used.
- `quantity`: Number of pizzas ordered.
- `unit_price`: Price per pizza.
- `total_price`: Total price for the order.

## Dashboard Insights

The Power BI dashboard includes the following key visualizations:

1. **Total Sales Analysis**: Displays total revenue generated from pizza sales.
2. **Top-Selling Pizzas**: Highlights the most popular pizza varieties.
3. **Sales by Category & Size**: Breakdown of sales by pizza type and size.
4. **Time-Based Sales Trends**: Analyzes peak order times and sales trends over time.
5. **Customer Preferences**: Identifies trends in pizza preferences based on sales data.

## How to Use

- Open the `.pbix` file in Power BI Desktop to view and interact with the dashboard.
- Use filters and slicers to explore specific sales data.
